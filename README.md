# InvestIntel · 统一投资驾驶舱 & 每日投研助手 V2.0

> **定位**：专为 **多券商（富途 / 老虎 / 长桥 / 国信）+ 三地市场（A股 / 港股 / 美股）** 打造的个人资产穿透驾驶舱与 AI 投研中枢。

### 🔒 隐私与安全三大军规
1. **零交易权限 (Strict Read-Only)**：第一阶段绝不接入券商交易下单接口，仅做成交导入、持仓同步与行情分析。
2. **凭证隔离 (Credential Isolation)**：券商 API Token、登录凭证、大模型 API Key 绝对禁止写入前端代码或提交至 Git 仓库，全部通过本地 `.env` 环境变量驱动。
3. **数据主权 (Self-Hosted Data)**：所有投资底稿、买卖理由、资金流水仅保存在本地 `data/*.json` 中，前端只做静态展示。

## 2. 六大核心模块设计规范

### ① Overview · 核心驾驶舱
- **Morning / Closing Brief**：晨报（美股收盘后/A股开盘前）回答：*昨夜发生了什么？对我今天的持仓有什么影响？今天需要重点观察什么？*；晚报（港A收盘后）回答：*今日损益主要由谁引起？是否需要调整夜盘美股操作？*
- **统一资产看板**：汇总 NAV、日盈亏、累计盈亏、现金储备比率、4券商各自资产。
- **24小时市场联动时间轴**：美股收盘(05:00) ➔ 晨报生成(07:30) ➔ A股开盘(09:30) ➔ 港股开盘(10:00) ➔ 午间总结(12:00) ➔ 收盘(16:00) ➔ 美股盘前(21:30)。

### ② Portfolio · 持仓穿透与合并
- **跨券商同标的合并**：例如腾讯控股同时分散在富途（700股）和长桥（300股），系统自动合并为 1,000 股，计算加权平均成本与合并仓位（10.4%）。
- **多维穿透矩阵**：
  - **行业敞口**：识别半导体、互联网、白酒消费、新能源等实际行业权重。
  - **币种敞口**：USD (37%) / CNY (35%) / HKD (28%)。
  - **底层因子**：穿透高 Beta 科技、红利防守、成长出海等风格因子。
- **个股“投资档案”抽屉**：点击任何股票即可展开其：
  - 为什么买（Thesis）
  - 核心跟踪验证指标（Key Metrics）
  - 逻辑失效/止损退出触发线（Invalidation Triggers）
  - AI 每日逻辑有效性巡检状态（NORMAL / WARNING / CRITICAL）

### ③ Intel · 持仓级情报局 (新闻 × 我的仓位)
拒绝无序的信息过载，将全网新闻划分为三级过滤：
- 🔴 **一级 (Level 1)**：直接涉及持仓公司（公告、财报、核心业务数据）。
- 🟠 **二级 (Level 2)**：产业链上下游与同业竞争对手（ASML 光刻机交付、抖音外卖策略等）。
- 🟡 **三级 (Level 3)**：宏观变量与外汇利率（美债 10 年期收益率、汇率、央行流动性）。
- **独家特性**：每条情报强制由 AI 附带 **「为什么与你的持仓有关 (Why it matters to you)」** 与 **「具体操作建议」**。

### ④ Risk Center · 风险与压力测试中心
- **集中度监测**：Top 5 持仓集中度（59.8%）、赫芬达尔指数（HHI）。
- **极端压力测试模拟器**：
  - *“如果纳斯达克暴跌 5%，我的组合会发生什么？”*（动态联动半导体 Beta 估算组合损益并给出对冲方案）。
  - *“恒生科技跌 5% / 沪深300跌 3% / 美元升值 2%”* 的交互式滑块实时推演。

### ⑤ Journal · 投资决策日志与复盘
- **买入强制档案化**：记录买入理由、预设持有周期、加仓条件、止损/逻辑失效底线。
- **闭环交易复盘**：平仓后自动测算 **Alpha（选股能力） vs Beta（市场大势） vs Luck（运气）** 归因。
- **AI 投资行为偏差诊断**：识别投资者心理偏误（如港股过早止盈、美股财报前追涨 FOMO）。

### ⑥ Copilot · 持仓感知型投研助手
- 预先加载完整持仓、成本、币种、投资 Thesis 上下文。
- 支持精确自然语言问答：
  - *“为什么我今天亏钱？”*
  - *“如果我要把英伟达仓位降到 8%，在各账户分别需要卖出多少股？”*
  - *“美团浮盈 25.7%，是否触及了我预设的退出条件？”*

## 4. 五大生产级 AI Prompt 体系

### Prompt 1: 每日晨报与风险定调 (Morning Brief Generator)
```text
[System Role]
你是一位拥有 20 年全球宏观对冲与三地市场管理经验的资深首席投资官（CIO）。

[Task]
根据用户提供的【昨夜全球主要市场收盘数据】以及用户【在富途、老虎、长桥、国信合并后的持仓明细】，生成一份高密度、拒绝废话的“今日投资晨报”。

[Input Context]
1. 用户持仓汇总 (JSON)
2. 现金与币种分布 (USD/HKD/CNY)
3. 昨夜纳指/标普/恒指/A股行情与关键宏观数据 (10Y美债、美元指数、油价)

[Output Format Requirements]
1. 组合今日风险定调：【低 / 中等 / 中等偏高 / 极高】
2. 核心结论（一句话，突出今日最核心矛盾）：例如“昨夜美股科技股走弱，半导体AI敞口拖累组合；A股消费防御起效；美团触及止盈线。”
3. 详细逻辑推演（不超过 200 字）：直接指出哪个标的拖累最大、属于 Beta 波动还是基本面破坏。
4. 今日行动清单（Actionable Checklist）：明确指出今天开盘后该关注哪 1-2 只股票、什么点位该如何处理。
```

### Prompt 2: 为什么今天亏/赚钱（盈亏归因引擎）
```text
[System Role]
你是一位量化绩效归因分析师（Brinson 绩效归因专家）。

[Task]
分析用户组合今日净值变动（例如 -1.08% / -¥26,340），输出多层次归因分析：
1. 个股层贡献与拖累：列出 Top 3 拖累项与 Top 3 贡献项（含具体个股金额与净值拖累百分比）。
2. 因子/行业层驱动：计算半导体、中国互联网络、白酒消费、大盘Beta、汇率变动对净值的各自贡献。
3. 解释本质：本次变动是由于用户选股的 Alpha 变化，还是单纯承受了市场 Beta 的系统性回撤？汇率（USD/CNY、HKD/CNY）带来了正收益还是负收益？
```

### Prompt 3: 新闻降噪与持仓关联（News × Portfolio Filter）
```text
[System Role]
你是个人投资情报主编，专为高净值投资人过滤噪音。

[Input]
- 今日抓取的新闻正文
- 用户持仓标的与行业列表

[Task]
1. 判定相关性等级：
   - 🔴 Level 1：直接涉及持仓公司
   - 🟠 Level 2：供应链核心上下游或关键竞争对手
   - 🟡 Level 3：对持有币种或估值折现率有实质影响的宏观变量
   - 无关则直接丢弃！
2. 撰写【为什么与你有关 (Why it matters to you)】：严禁复述新闻，必须直接挂钩用户持仓权重和金额！
3. 给出明确的操作指引（维持持有 / 逻辑受损观察 / 准备分批止盈 / 逆势加仓机会）。
```

### Prompt 4: 个股投资逻辑有效性巡检 (Thesis Invalidation Checker)
```text
[System Role]
你是负责风控与投资纪律审查的合规委员会主席。

[Task]
对比某只个股建仓时填写的【投资理由】、【核心跟踪指标】、【退出/失效条件】，对照今日最新财报、新闻与价格走势，给出裁决：
- NORMAL：投资假设完好无损。
- WARNING：出现短期估值偏高、行业敞口超标或指标小幅弱化。
- CRITICAL：触发建仓时预设的止损线、逻辑被证伪、或达到预设止盈线。
输出清晰明确的警示理由，防止投资人因为沉没成本而为亏损寻找借口。
```

### Prompt 5: 投资决策复盘与行为偏误诊断 (Trade Post-Mortem & Behavioral Diagnostics)
```text
[System Role]
你是一位行为金融学（Behavioral Finance）专家与交易心理导师。

[Task]
对用户已完成平仓的交易进行全面归因：
1. 盈亏拆解：本次收益中，市场贝塔（大盘上涨贡献）占多少？个股阿尔法（选股超额）占多少？运气成分（偶发事件/并购/突发利好）占多少？
2. 行为模式挖掘：
   - 是否存在港股/A股“过早止盈，卖飞大牛股”的处置效应？
   - 是否存在美股财报公布前因 FOMO（错失恐惧）追高建仓的冲动行为？
   - 是否存在止损滞后、浮亏加仓拉低成本的风险扩大倾向？
3. 输出下一阶段的针对性行为处方（Prescription）。
```

## 5. 快速启动与运行指南

### 方法 A: 直接在浏览器中双击运行 (纯前端模式)
1. 直接用 Edge / Chrome 浏览器双击打开项目根目录下的 `index.html`。
2. 页面已内置容错机制，在 `file://` 协议下自动激活完整的四券商穿透样例数据，所有 6 个主标签页、投资档案弹窗、压力测试滑块、Copilot 智能问答均可立即交互！

### 方法 B: 本地轻量静态服务器运行
```powershell
# 方式 1: 使用 Python 内置服务器
python -m http.server 8080

# 方式 2: 使用 Node.js serve
npx serve .
```
打开浏览器访问: `http://localhost:8080`

### 方法 C: 运行本地数据聚合计算脚本
```powershell
# 运行持仓穿透聚合计算（自动计算 NAV、合并同代码持仓、计算行业/币种占比）
python scripts/sync_data.py --mode calc
```
